1. Contador de digitos
Este programa solicita un numero entero al usuario y utiliza un ciclo while para contar la cantidad de digitos que contiene.

2. FizzBuzz
Este programa solicita un numero n y utiliza un ciclo for para recorrer los numeros desde 1 hasta n. Los multiplos de 3 se muestran como "Fizz", los múltiplos de 5 como "Buzz" y los multiplos de ambos como "FizzBuzz".

3. Numero invertido
Este programa solicita un numero entero y utiliza un ciclo while para invertir el orden de sus digitos.

4. Suma de pares e impares
Este programa solicita un numero n y utiliza un ciclo for para calcular por separado la suma de los numeros pares y la suma de los numeros impares desde 1 hasta n.

5. Piramide de asteriscos
Este programa solicita la altura de una piramide y utiliza un ciclo for para dibujar una piramide de asteriscos de la altura indicada.

Estructuras utilizadas
En los cinco programas se utilizan ciclos for y while, ademas de estructuras condicionales if, elif y else cuando son necesarias.

Los programas también utilizan variables, operadores aritmeticos, operadores de comparacion, input(), print() y range().
